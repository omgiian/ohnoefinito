# Oh no, è finito!

Lista condivisa di ciò che è finito in casa (cibo, prodotti per la pulizia, igiene…).

- **Casa**: lista condivisa, la vede e la modifica chiunque abbia accesso alla pagina.
- **Solo mio**: lista personale, visibile solo a te.

La pagina (`index.html`) è pubblicata come Artifact su claude.ai e salva i dati nel database condiviso dell'artifact.
